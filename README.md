# SwitcherNative 🇺🇦🇨🇦

Нативний, надшвидкий та безпечний перемикач клавіатурної розкладки для **macOS** (оптимізований під **Apple Silicon M-серії: M1/M2/M3/M4** та **macOS 14+ / Tahoe / macOS 27+**).

Працює нативно на Swift без використання Rosetta, не має жодних зовнішніх залежностей, не здійснює мережевих запитів та поважає приватність.

---

## ✨ Основні можливості

- **Автоматичне виправлення «на льоту»**: аналізує слово після введення (Space, Enter, Tab) та виправляє помилкову розкладку (`gthtlevjdf` ➔ `передумова`, `руддщ` ➔ `hello`, `пшерги` ➔ `github`).
- **Підтримка 2 системних розкладок (Українська та English)**:
  - Коректна обробка російських символів (`ы`, `э`, `ъ`, `ё`), що вводяться через клавішу **Option** в українській розкладці.
- **Гаряча клавіша виправлення — Лівий Command (⌘)**:
  - Одинарний короткий тап виправляє поточне або останнє надруковане слово.
  - **Циклічний відкат (Toggle / Undo)**: повторне натискання Command миттєво повертає слово в попередній стан, якщо ви змінили його випадково.
  - Виправлення виділеного фрагмента тексту.
- **Слова-виключення (User Exceptions)**:
  - Можливість додавати власні слова, абревіатури чи команди (`yt`, `cmd`, `sql` тощо) через меню програми, щоб вони ніколи не перемикалися автоматично.
- **Безпека та приватність**:
  - Автоматичне вимкнення в полях вводу паролів (`IsSecureEventInputEnabled`).
  - Виключення для терміналів та середовищ розробки (Terminal, iTerm2, VS Code, Xcode, Sublime Text, Alacritty, Nova).
  - 100% офлайн (жодних телеметрій чи інтернет-запитів).
- **Зручне меню у Menu Bar**:
  - Адаптивна іконка під Dark/Light режим.
  - Індикатор поточної розкладки.

## 🛠 Збірка з вихідного коду

### Вимоги:
- Mac на Apple Silicon (M1 / M2 / M3 / M4) або Intel.
- macOS 13.0 або новіша (включаючи macOS 26/27).
- Встановлені Xcode Command Line Tools:
  ```bash
  xcode-select --install
  ```

### Збірка:
```bash
git clone https://github.com/ВАШ_ЛОГІН/SwitcherNative.git
cd SwitcherNative
chmod +x build_app.sh
./build_app.sh
```

Готовий додаток `SwitcherNative.app` буде скомпільовано та підписано. Щоб встановити його у систему:
```bash
cp -R SwitcherNative.app /Applications/
open /Applications/SwitcherNative.app
```

## 🔒 Дозволи (macOS Permissions)

При першому запуску відкрийте:
**Системні параметри → Приватність і безпека → Доступність (Accessibility)** 
та увімкніть дозвіл для **SwitcherNative**.
